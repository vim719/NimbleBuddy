Features

A companion, not a chatbot.

Everything happens by voice, in real time, with a personality that stays warm and wholesome.

Real-time voice

Speak naturally and interrupt any time. Speech-to-text, LLM and a lifelike voice stream over a low-latency real-time network.

Cross-session memory

Tell Maya your name and she remembers what you talked about last time — stored per user and re-injected on your next call.

Live web search

Ask about news, weather or anything recent. Maya calls Nimbleway's nimble_search tool over MCP and answers in a sentence or two.

Chrome extension

Talk to Maya from the toolbar without opening a tab — a Manifest V3 popup on the same backend, memory and search.

Run it

Try Maya on your machine.

You'll need real-time voice credentials (App ID + Certificate), and a Nimbleway API key for web search.

1 · Web app

Clone, add your keys to server/.env.local, start both servers, open localhost:3000.

git clone https://github.com/vim719/NimbleBuddy
cd NimbleBuddy
bun run setup
# add your voice App ID, App Certificate
# and Nimbleway API key to server/.env.local
bun run dev

2 · Chrome extension

With the backend running, build the popup (or unzip the download) and load it unpacked.

cd extension
bun install && bun run build
# chrome://extensions → Developer mode
# → Load unpacked → extension/dist

Why no live demo link? Maya's backend holds the voice App Certificate and API keys, so it runs server-side rather than on GitHub Pages. Clone and run locally in about two minutes.
